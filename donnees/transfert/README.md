# Variantes de transfert

Ces variantes remplacent la question de transfert de l’étape correspondante. Elles se traitent en trois minutes environ,
dans le budget du TP, après le contrôle de référence. Aucun TP supplémentaire ni livrable séparé.

Répondre en trois phrases : **observation** (fait et périmètre), **conclusion** (ce que les faits autorisent),
**prochaine action** (vérification concrète).

| TP | Variante | Support |
| --- | --- | --- |
| 01 | Charge : seuil 85 au lieu de 80 | PARC dans ateliers/01 |
| 02 | Quatrième champ absent d’une ligne | parc_champ_absent.csv |
| 03 | Mémoire à 91 %, services inaccessibles | Cas oral : observations fictives |
| 04 | Autre format d’événement et seuil 2 puis 3 | auth-variante.log |
| 05 | Filtre SQLite à 3 au lieu de 2 | Rapport de référence |
| 06 | Une cible ne répond pas | collecte-partielle.csv |

Utiliser les fonctions écrites ou leurs références pour vérifier une prédiction. Créer une sortie neuve pour les essais.
Conserver les données de référence : les contrôles habituels restent fondés sur elles. Les mesures du cas 03 et les
cibles du cas 06 sont fictives.
